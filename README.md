# roytalex — сайт-портфолио

Лендинг Александра Ройтберга (`roytalex`): IT-блогер и мини-бизнесмен.

## Запуск

Открой `index.html` в браузере или подними локальный сервер:

```bash
python3 -m http.server 8080
```

Затем зайди на http://localhost:8080

## Что править под себя

В `index.html` ищи комментарии `<!-- ЗАМЕНИ ЭТОТ ТЕКСТ -->`:

- блок после клика по компьютеру (`#bootPanel`)
- секция «Моя история» (`#story`)
- ссылки в «Связаться» (`#contact`)

## Анимации

- кликабельный ноутбук с boot-экраном
- живой терминал с печатью навыков
- орбита технологий
- падающий код на фоне
- появление навыков при скролле
