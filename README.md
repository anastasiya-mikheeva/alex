# Roytalex

Научная платформа **Roytalex** — википедия будущего: статьи, обучение, голосовой помощник и ChatRoyt.

## Страницы

- `index.html` — главная
- `akk.html` — профиль редактора
- `mes.html` — мессенджер
- `pay.html` — оплата и подписка
- `chat.html` — ChatRoyt

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8080
```

Затем перейдите на `http://localhost:8080`.
